# Исследование Q-learning в GridWorld

Вся учебная работа находится в `RL_GridWorld.ipynb`. Я проверяю, помогает ли награда за приближение к цели обойти стену. В ноутбуке есть постановка, код, таблицы, графики и выводы.

Сравниваю обычную награду, манхэттенскую подсказку и два масштаба потенциала по кратчайшему пути. Один из них имеет тот же диапазон, что и манхэттенский. Использую десять seed и одинаковый бюджет 80 000 шагов. Помимо успешности измеряю достижение прохода и долю столкновений на шаг.

Для запуска откройте ноутбук в Jupyter или Colab и выполните все ячейки. Первая кодовая ячейка устанавливает библиотеки. Если потребуется перезапуск сеанса, выполните все ячейки заново после перезапуска. Код проверен в локальном Jupyter на Python 3.12.0. Запуск в Colab отдельно не проверялся.
